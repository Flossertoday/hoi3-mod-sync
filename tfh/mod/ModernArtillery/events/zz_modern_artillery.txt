#################################################################
# Modern Artillery - player-only events (v3, 2026-11-09)
#
# v3 display change (the granted technology values did NOT change):
#   The hidden technology modern_artillery_tech carries the real values.
#   v2 additionally declared a fake triggered modifier (modern_artillery_buff)
#   whose four effects did NOT match the real buff. That modifier is removed
#   in v3; the numbers are now shown by:
#     * event 9900003 - compact detail popup, fired right after the grant;
#     * the passive decision modern_artillery_buff_info in
#       decisions/zz_modern_artillery.txt - hover its name in the diplomatic
#       decision list for the full value sheet.
#   Both texts are generated from the technology file + vanilla unit baselines
#   by scripts/artillery/gen_buff_localisation.py (single source of truth).
#
# Grant mechanics (unchanged since v2):
#   event effect <tech> = N runs one AdvanceResearch call with N*1000
#   leadership. N=1 was far below the research cost (about 137.5 leadership
#   days), so v1 never levelled the tech up. N=5000 (about 36x the cost)
#   guarantees exactly +1 level; the technology is max_level = 1.
#   change = no makes existing artillery brigades catch up for free in 1 day.
#
# 9900001 - fresh grant (flag not set yet): set flag + grant + popup 9900003.
# 9900002 - migration for old saves (flag set, tech level still 0) + popup.
# 9900003 - triggered-only detail popup (no trigger, never in the MTTH pool).
# Player only: ai = no; fire_only_once stops repeated grants.
#################################################################
